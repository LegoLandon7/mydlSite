MYODL API

REST API — session auth via Discord OAuth - AI GENERATED DOCS

https://api.myodl.net

Auth OAuth

Discord OAuth2 flow. Sessions persist for 7 days via signed cookies.

GET /auth/login Start OAuth flow ▶
Query params
NameTypeDescription
redirectstringoptionalURL to redirect to after login
Redirects browser to Discord. On success redirects back to redirect or /.
GET /auth/callback OAuth callback ▶
Handled automatically by Discord redirect. Sets session cookie and upserts user record.
GET /auth/me Get current session ▶
Returns
discord_idYour Discord snowflake
usernameDisplay name
avatar_urlCDN avatar URL or null
Returns 401 if not logged in.
GET /auth/logout Clear session ▶
Clears the session cookie.

Groups Auth required for most

Create groups, manage members, track completions with dynamic point rankings.

GET /groups/ All groups paginated ▶
Query params
pageintoptionalDefault 1
Rate limit: 60/min
GET /groups/search Search groups by name ▶
Query params
qstringrequiredMin 2 characters
Rate limit: 30/min
GET /groups/me Your groups (owned + joined) ▶
🔒 Auth required
Includes your role and join_status in each group.
Rate limit: 60/min
GET /groups/{group_id} Group detail + members ▶
Returns group info and full member list with roles and join status.
Rate limit: 60/min
GET /groups/{group_id}/levels Group level list with completions ▶
Each level includes a completions array of accepted submissions. Points are 1–500, dynamically calculated by group position (rank 1 = 500).
Rate limit: 60/min
GET /groups/{group_id}/leaderboard Points leaderboard ▶
Ranked by sum of points for accepted 100% completions only.
Rate limit: 60/min
GET /groups/{group_id}/join-requests Pending join requests ▶
🔒 Admin or owner
Rate limit: 30/min
POST /groups/ Create a group ▶
🔒 Auth required — max 10 owned groups
Body (JSON)
FieldTypeDescription
namestringrequired2–64 characters
descriptionstringoptionalMax 500 chars
discord_linkstringoptionaldiscord.gg/ or discord.com/invite/
video_requiredbooloptionalRequire video on all submissions, default false
Rate limit: 10/min
PATCH /groups/{group_id} Update group settings ▶
🔒 Owner only
Body (JSON) — all fields optional
namestring2–64 characters
descriptionstringMax 500 chars
discord_linkstringnull to clear
video_requiredbool
Rate limit: 10/min
POST /groups/{group_id}/join Request to join ▶
🔒 Auth required — max 50 groups
Sends join request and notifies all admins and the owner. All groups are request-only.
Rate limit: 20/min
POST /groups/{group_id}/join/{user_id}/approve Approve join request ▶
🔒 Admin or owner
Sends join_approved notification to user.
Rate limit: 30/min
POST /groups/{group_id}/join/{user_id}/deny Deny join request ▶
🔒 Admin or owner
Removes pending request and sends join_denied notification.
Rate limit: 30/min
POST /groups/{group_id}/sync Sync personal list to group ▶
🔒 Approved member
Queues pending submissions for every personal list level that exists in the group's list. Skips levels with a pending submission already open, or where accepted record is already equal or higher. Returns queued count.
Rate limit: 10/min
POST /groups/{group_id}/levels Add level to group list ▶
🔒 Admin or owner
Body (JSON)
level_idintrequired
positionintrequired≥ 1 — existing entries shift down if taken
Points for all levels recalculate immediately after insert.
Rate limit: 20/min
PATCH /groups/{group_id}/levels/{level_id}/position Reorder a level ▶
🔒 Admin or owner
Body (JSON)
level_idintrequired
positionintrequiredNew position ≥ 1
Rate limit: 20/min
PATCH /groups/{group_id}/members/{user_id}/role Change a member's role ▶
🔒 Owner only
Body (JSON)
user_idstringrequired
rolestringrequiredadmin or member
Rate limit: 20/min
DELETE /groups/{group_id}/members/{user_id} Remove member / leave group ▶
🔒 Self, admin, or owner
Deletes all accepted submissions for that user in this group.
Rate limit: 30/min
DELETE /groups/{group_id}/levels/{level_id} Remove level from group ▶
🔒 Admin or owner
Points recalculate immediately.
Rate limit: 20/min
DELETE /groups/{group_id} Delete group ▶
🔒 Owner only
Cascades: deletes all submissions, notifications, members, and levels for this group.
Rate limit: 10/min

Submissions Auth required

Submit levels to groups, track queue position, accept or reject as admin.

POST /submissions/ Submit a level to a group ▶
🔒 Approved member
Body (JSON)
FieldTypeDescription
group_idintrequired
level_idintrequiredMust be in group's level list
recordintoptional1–100, default 100
video_linkstringoptionalRequired if group has video_required
Can't submit if a pending submission already exists for this level. Resubmit after accepted only if new record is higher.
Rate limit: 20/min
GET /submissions/me Your submissions ▶
🔒 Auth required
Query params
pageintoptionalDefault 1
group_idintoptionalFilter to a specific group
Rate limit: 30/min
GET /submissions/me/queue/{group_id} Queue position in a group ▶
🔒 Auth required
Returns
pending_countYour open submissions in this group
submissions_aheadTotal submissions from any user submitted before your earliest
submissionsYour pending submission objects
Rate limit: 30/min
GET /submissions/group/{group_id} All submissions for a group ▶
🔒 Admin or owner
Query params
pageintoptionalDefault 1
statusstringoptionalpending | accepted | rejected
Rate limit: 30/min
POST /submissions/{submission_id}/accept Accept a submission ▶
🔒 Admin or owner
Sets status to accepted, records reviewed_at, and sends submission_accepted notification to the submitter.
Rate limit: 30/min
POST /submissions/{submission_id}/reject Reject a submission ▶
🔒 Admin or owner
Sets status to rejected, records reviewed_at, and sends submission_rejected notification to the submitter.
Rate limit: 30/min

Notifications Auth required

Stored permanently, never deleted. Marked read/unread manually.

GET /notifications/ Your notifications ▶
🔒 Auth required
Query params
pageintoptionalDefault 1
unread_onlybooloptionalDefault false
Notification types
submission_acceptedYour submission was accepted
submission_rejectedYour submission was rejected
join_requestSomeone wants to join your group (admin/owner)
join_approvedYour join request was approved
join_deniedYour join request was denied
Response includes unread_count at the top level alongside pagination.
Rate limit: 60/min
GET /notifications/unread-count Unread badge count ▶
🔒 Auth required
Lightweight endpoint for polling. Returns {"unread_count": N}.
Rate limit: 60/min
POST /notifications/{notif_id}/read Mark one as read ▶
🔒 Auth required — must be yours
Rate limit: 60/min
POST /notifications/read-all Mark all as read ▶
🔒 Auth required
Rate limit: 20/min
